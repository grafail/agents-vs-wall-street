Blind-then-reconcile earnings forecaster — Agents vs Wall Street, 16 Aug 2026

The idea in two sentences: the LLM is the analyst, the code is the calculator. The model reads filings, researches live evidence and expresses bounded, cited judgments — it never writes a final number. Deterministic code computes every figure from exact extracted anchors, backtests its own statistical methods, caps the model’s influence at 0.75× the measured backtest error, and guarantees a sane number in every cell even when stages fail.

Why it’s built this way — 5 rules

Assumptions, not numbersLLMs mis-generate absolute digits; they judge relative change well. Model outputs deltas/labels; Python does all arithmetic on exact anchors.
Blind, then reconcileConsensus is withheld from the estimator (anchoring bias), then confronted at a separate step: defend the gap with evidence or revise. Scoring is relative to Wall St — deviations must be earned.
Backtest before trustEvery statistical method is walk-forward tested per metric on the company’s own history; the winner’s measured error becomes the LLM’s influence budget.
Never blankMissing cell = worst score. Fallback ladder: estimator → best baseline → guidance mid → consensus → last-year anchor; every skip logged with a reason.
Cache-firstStable-prefix prompts (provider cache) + read-through disk cache for all external data. Pre-baking the day = warming caches; the final run is fast, cheap and wifi-resilient.

Depth on demand

Data & trust: extraction funnel, tiers, restatements
  • Deterministic search narrows the frozen 1,139-doc corpus to candidate excerpts (strong-number line gate, per-metric synonyms); the small model parses excerpts to typed facts; a fact is rejected unless its raw value string-matches inside its own quoted source line (hallucination gate). ~160 facts/company, <$1, run once, committed.
  • Every fact carries source doc, published date, fetch time, trust tier (1 corpus filings/RNS · 2 IR/official macro · 3 aggregators & peers · 4 news = leads only — can feed a vibe, never move a number alone). Higher tier wins conflicts; newer publication wins within a tier — fired in practice on Hays’ continuing-operations restatement (583.3 vs 496.0 for the same period).
  • Unambiguous unit slips (×100 pence, ×1000 scale) are auto-corrected with an audit flag when exactly one canonical factor fits; ambiguous cases flagged, never guessed.
The judgment layer: quantiles, vibes, caps
  • Estimator returns p10/p50/p90 relative deltas + three categoricals (momentum, guidance style, surprise skew), each explanation-before-label with citations — an uncited label contributes exactly zero.
  • Quantile influence is shrunk by the model’s own stated uncertainty: shrink = 1/(1+(p90−p10)/σ). Zero spread is treated as overconfidence and penalized, not rewarded.
  • Total adjustment clamped to 0.75 × chosen method’s backtest MAE; tiny-sample MAEs (n<3) are floored; when σ is unavailable the MAE provides the scale — every degradation writes an audit note.
Validation & reliability: gates, containment, tests
  • History-adaptive magnitude bands (a series that halves yearly gets a band that tolerates halving; sign-flips vs consistent history fail); pence/pounds and percent/decimal traps; unit-consistency asserts; guidance-range sanity. All logged pass/fail per candidate.
  • Containment: metric failure → fallback ladder; company failure never stops the others; LLM calls retry once; failed research yields an empty digest, not a dead run.
  • 154 pytest tests over deterministic layers (converters, baselines, backtests, caps, gates, writer). LLM/network mocked; real corpus files as fixtures; templates sha-asserted unmodified.
What we tried, changed, or got wrong
  • OpenBB adopted then dropped the same hour — a lean keyless tool belt (yfinance/ddgs/trafilatura) was more debuggable.
  • Guessed the wrong golden document (Hays Aug-3 filing = admin notice); the pipeline found the real July-10 pre-close on its own.
  • Blind-integrity leak found & sealed: Hays’ RNS publishes company-compiled consensus; extraction first classed it as guidance — a street number sat in the blind context. Now typed consensus_*, routed only to the reconciler (and it became our best consensus source).
  • Silent self-muting: with a 2-point series, σ=None zeroed all judgment without a trace. Fixed + a sweep found four sibling bugs (tiny-n caps, overconfidence reward, unlogged scout tokens, uncached digest).
  • Fixed bands rejected true values: the 0.5–2×-median gate called Hays’ genuine EPS collapse a “unit error”; bands now derive from the series’ own YoY ratios.
Known weaknesses (unresolved, disclosed)
  • Blindness controls the context, not the model’s pretrained priors — famous tickers carry consensus-shaped memory. Anonymization was rejected (costs peer knowledge); we disclose instead.
  • Run-to-run estimator variance is real (~12% swing observed on one metric between identical runs). Self-consistency sampling is designed but deferred — our most acknowledged gap if unshipped.
  • Vibe σ-multiples are declared, not fully calibrated (time-travel calibration designed, may not ship); caps + citations-or-zero are the defence.
  • Sparse annual histories (Hays) leave some backtests at n=1–3; we floor error scales rather than trust tiny samples.
  • yfinance consensus mapping is the least-verified seam; corpus-published consensus + magnitude gates reduce, not eliminate, the risk.
Reproduce it
  • uv sync rebuilds the exact env (Python 3.13, lockfile committed); keys/models via .env (MODEL_BIG/MODEL_SMALL, OpenRouter or OpenAI).
  • Prepare (re-runnable, parallel): uv run python -m pipeline.run --prepare --all [--refresh]
  • Final command: uv run python -m pipeline.run --forecast --all → 4 workbooks + logs/run-<ts>/{events.jsonl, report.json, report.html}, ending with the contest submission check.
  • Cost: dev iteration on DeepSeek (~$0.11/company run); final on GPT-5.6 Sol (estimate/reconcile) + Luna (extraction/research), ~$5–6 per full run against the $50 budget. Every call’s tokens, cache hits included, are in the run log.
