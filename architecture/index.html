Agents of S.T.O.C.K.

Blind-then-reconcile earnings forecaster — Agents vs Wall Street, 16 Aug 2026

The idea: the AI is the analyst, the code is the calculator. The agent reads the filings, does its own research and forms a judgment — but every judgment is cited, capped by measured error, and turned into the final number by plain, testable code. It never writes a figure itself.

What makes this architecture strong

The agent does the hard workreads a 1,139-document corpus, plans its own web research, weighs the evidence — a person runs one command and reviews the result.
Every number is explainedeach figure ships as a worksheet: which line is data, which is math, which is model judgment — with citations. Nothing is just asserted.
Judgment on a leashthe model may move a number by at most 0.75× the error its statistics historically make. Trust is measured, not assumed.
Cost-efficient & rerunnablecaching at every layer; ~$0.06 per company in development, ~$5–8 for a full premium run — so it can be run again and again all day.
Flexible across modelsmodels are configuration, not code — and it can ask several models at once (a cross-provider panel): where they disagree, the system automatically trusts them less.
Rich, trusted datafrozen filings corpus + live news/market/web tools; every fact carries its source, date and a trust tier that decides conflicts.
Fails safea blank cell scores worst-possible, so a fallback ladder guarantees a sane number even when stages fail — loudly flagged, never silent.

Main choices, one line each

Fixed pipeline, agentic insidethe agent has freedom exactly where judgment lives (research, estimate, reconcile) and none where correctness lives (math, units, output).
Blind, then reconcilethe estimator never sees Wall Street’s number; a separate step then makes it defend any gap with evidence, or revise.
Backtest before trustevery statistical method is rehearsed on the company’s own history first; the winner’s measured error sets the agent’s influence budget.
Two-stage dayresearch and extraction are prepared and cached in advance; the final run is fast and independent of venue wi-fi.
Small model for volume, big for judgmentextraction and research run on a cheap model; only estimation and reconciliation use the expensive one.

Code: the cap that limits the model’s influence
# nudges.py — the model's total adjustment can never exceed
# 0.75x the error its chosen statistical method makes historically
cap = 0.75 * backtest_mae
adjustment = max(-cap, min(cap, raw_adjustment))

And an uncited opinion counts for nothing:

# a categorical "vibe" with no citations contributes exactly zero
if not grounded.citations:
    return {"label": label, "value": 0.0, "source": "empty_citations_zeroed"}
Code: what the model is allowed to say
class Grounded(BaseModel):      # explanation FIRST — reason, then classify
    explanation: str
    label: Literal["cold","cooling","neutral","warming","hot"]
    citations: list[str]

class Estimate(BaseModel):      # no absolute numbers anywhere in here
    growth_p10: float; growth_p50: float; growth_p90: float
    momentum: Grounded
    guidance_style: Grounded
    surprise_skew: Grounded

The model’s entire output is bounded deltas and labeled opinions — code does the rest.

Data & trust
  • Search narrows the corpus → small model parses excerpts → fact rejected unless its value appears verbatim in its own quote.
  • Facts carry source, date, trust tier (filings > IR > aggregators > news). Higher tier wins; newer wins within a tier (restatements supersede).
  • Unambiguous unit slips auto-corrected with an audit flag; ambiguous ones flagged, never guessed.
Validation & reliability
  • Gates: history-adaptive magnitude bands, sign-flip check, pence/percent traps, guidance sanity — all logged.
  • Failures degrade, never crash: metric → fallback ladder; company failures isolated; calls retried.
  • 176 tests on the deterministic layers; LLM/network mocked; templates sha-asserted untouched.
What we tried, changed, or got wrong
  • OpenBB in, then out same hour — lean tools won.
  • Guessed the wrong “golden document” for Hays; the pipeline found the real one itself.
  • Company-compiled consensus leaked into the blind context as “guidance” — sealed, and it became our best consensus source.
  • σ=None silently zeroed all judgment; fixing it surfaced four sibling bugs.
  • Fixed bands called a real EPS collapse a “unit error” — bands now adapt to each series.
  • Metrics estimated in isolation produced flat profit + collapsing EPS — now one company-level call + a coherence gate.
Known weaknesses
  • Blindness can’t erase pretrained consensus-shaped priors; disclosed, not anonymized.
  • Estimator variance between runs (~12% seen once); mitigated by the model panel, not eliminated.
  • Vibe σ-multiples declared, not calibrated; caps are the defence.
  • Some backtests sit on 1–3 samples; error scales floored.
  • yfinance consensus mapping is the weakest seam.
Reproduce it
  • uv sync; keys/models in .env.
  • Prepare: uv run python -m pipeline.run --prepare --all
  • Final: uv run python -m pipeline.run --forecast --all → 4 workbooks + full run log/report.
  • Billed cost logged per call; a full premium run is ~$5–8 of the $50 budget.
