Agents of S.T.O.C.K.

Blind-then-reconcile earnings forecaster — Agents vs Wall Street, 16 Aug 2026

The idea: the AI is the analyst, the code is the calculator. The agent reads the filings, does its own research and forms a judgment — but every judgment is cited, capped by measured error, and turned into the final number by plain, testable code. It never writes a figure itself.

What makes this architecture strong

The agent does the hard workreads a 1,139-document corpus, plans its own web research, weighs the evidence — a person runs one command and reviews the result.
Every number is explainedeach figure ships as a worksheet: which line is data, which is math, which is model judgment — with citations. Nothing is just asserted.
Judgment on a leashthe model may move a number by at most 0.75× the error its statistics historically make. Trust is measured, not assumed.
Cost-efficient & rerunnablecaching at every layer; cents per company in development, a few dollars for a full premium run — so it can be rerun all day.
Flexible across modelsmodels are configuration, not code — it can ask several models at once (a cross-provider panel): where they disagree, the system automatically trusts them less.
Rich, trusted datafrozen filings corpus + live news/market/web tools; every fact carries its source, date and a trust tier that decides conflicts.
Fails safea blank cell scores worst-possible, so a fallback ladder guarantees a sane number even when stages fail — loudly flagged, never silent.

How every number is assembled — the worksheet

This five-row recipe is the system’s core contribution. Every one of the 12 submitted figures is built exactly this way, and the run report shows the filled-in version of this worksheet for each:

[D]  anchor      what the company actually reported last time     ← quoted from the filing
[M]  baseline    a statistical starting forecast                  ← the method that rehearsed best on this metric's own past
[L]  judgment    the AI’s adjustment — cited, self-shrunk, capped  ← at most 0.75× the baseline’s measured error
[M]  check       compared to Wall Street: defend the gap or blend ← the only place consensus is allowed in
[M]  ship        sanity gates pass → the cell; a rung fails → the next rung takes over, flagged

[D] data · [M] deterministic math · [L] model judgment. In one live run the model pushed a metric negative; the gates refused, a flagged fallback shipped, and that report led us to a better statistical method — the worksheet is also our debugger.

Main choices, one line each

Fixed pipeline, agentic insidefreedom exactly where judgment lives (research, estimate, reconcile); none where correctness lives (math, units, output).
Blind, then reconcilethe estimator never sees Wall Street’s number; a separate step makes it defend any gap with evidence, or revise.
Backtest before trustevery statistical method is rehearsed on the company’s own history first; the winner’s error sets the AI’s influence budget.
Company-level estimationone blind call sees all of a company’s metrics together, so profit and EPS can’t drift apart.
Two-stage dayresearch and extraction are prepared and cached in advance; the final run is fast and wi-fi-proof.

Honest notes

Tried, changed, got wrong

  • OpenBB in, then out — lean tools won.
  • Guessed the wrong “golden document”; the pipeline found the real one itself.
  • Published consensus leaked into the blind context as “guidance” — sealed, then reused as our best consensus source.
  • A sparse series silently zeroed all model judgment; the fix surfaced four sibling bugs.
  • Metrics estimated in isolation gave flat profit + collapsing EPS — hence company-level estimation.

Still weak, knowingly

  • Blindness can’t erase pretrained consensus-shaped priors; disclosed, not anonymized.
  • Run-to-run estimator variance; damped by the model panel, not eliminated.
  • Vibe mappings declared, not calibrated; the cap is the defence.
  • Some backtests rest on 1–3 samples; error scales are floored.
  • The yfinance consensus mapping is the weakest seam.
