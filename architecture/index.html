Agents of S.T.O.C.K.

A blind-then-reconcile earnings forecaster — Agents vs Wall Street, 16 August 2026

What it does, in one paragraph. One command forecasts 12 reported financial metrics (Home Depot, Analog Devices, Hays, Deere × 3 each) and writes the four contest workbooks plus a fully-audited run log. The system’s core idea is a strict division of labour: the LLM is the analyst, the code is the calculator. The model never writes a final number — it reads documents, decides what to research, and expresses bounded, cited judgments (growth quantiles, categorical “vibes”). Deterministic code turns those judgments into figures on top of exact anchors extracted from filings, backtests every statistical method it uses, caps the model’s influence at a measured error budget, and guarantees a sane number in every cell even when everything upstream fails.

The pipeline

How a number is actually made

Every figure is assembled in layers, each visible in the run report as a worksheet with provenance tags (Ddata Mmath Lmodel judgment):

exact anchor → backtested baseline → calibrated guidance-beat → bounded judgment nudges → gated consensus blend
  • Anchors are exact. Last year’s reported figure, extracted with a verbatim quote; a fact is rejected unless its raw value string-matches inside its own quoted source line (hallucination gate).
  • Baselines are backtested, per metric. Five deterministic methods (seasonal YoY, growth drift, guidance midpoint, guidance × historical beat factor, H1-ratio for half-year reporters). Each is walk-forward tested on the company’s own history — fit strictly on data before each past period, predict it, score it. The method with the smallest measured error wins and its MAE becomes the judgment budget.
  • Judgment is bounded. The model’s quantile view is shrunk by its own stated uncertainty (shrink = 1/(1+(p90−p10)/σ)); categorical vibes map to fixed σ-multiples and are zeroed if uncited; the total adjustment is clamped to 0.75 × the chosen method’s backtest MAE. The model can move a number by at most three-quarters of the error the statistics themselves make.
  • Blindness is structural. The estimator’s context builder has no consensus input; the research agent’s market-data tool returns an error for estimate requests; consensus-attributed figures found in filings are typed consensus_* and routed only to the reconciler.

[L]  judgment — p50, momentum, skew: cited, shrunk, capped at ±0.75×MAE

This metric is also our favourite honest story: in the first end-to-end run both the estimator and the drift baseline extrapolated the collapse into negative EPS, every gate correctly refused, and the failsafe shipped last year’s value loudly flagged “needs manual review”. Inspecting that report led to the H1-ratio method — which dissolved the fallback into a backtested estimate.

Data & trust

  • Extraction funnel: deterministic search narrows the frozen 1,139-document corpus to candidate excerpts (strong-number line gate, per-metric synonyms); the small model parses excerpts into typed facts; deterministic code normalizes units. ~160 facts per company set, <$1 of tokens, run once and committed.
  • Every fact knows its provenance: source doc, published date, fetch time, and a trust tier (1 corpus filings/RNS · 2 IR & official macro · 3 aggregators & peer filings · 4 news = leads only, can feed a vibe but never move a number alone). Higher tier wins conflicts; newer publication wins within a tier (restated comparatives supersede as-reported — this fired in practice on Hays’ continuing-operations restatement).
  • Live tools are cached read-through (key = tool+args, fetched_at stamped, hit/live logged). Pre-baking the day’s research = warming this cache; the final run works from warm caches but can still fetch.

Validation & reliability

  • Gates (all deterministic, all logged per candidate): history-adaptive magnitude bands (a series that halves yearly gets a band that tolerates halving; sign-flips vs a consistently-signed history fail); pence-vs-pounds and percent-vs-decimal traps; unit-consistency asserts; guidance-range sanity.
  • Unambiguous unit slips are auto-corrected at extraction (×100 pence, ×1000 scale) — only when exactly one canonical factor lands the value in-band — and carry an audit flag; ambiguous cases are flagged, never guessed.
  • The never-blank cascade: estimator → best baseline → guidance midpoint → consensus → last-year anchor. Each rung is gate-checked; every skip is logged with its reason; a missing cell scores the contest maximum penalty, so some sane number always ships — loudly flagged when it arrived via fallback.
  • Containment: a metric failure degrades to the cascade; a company failure never stops the others; estimator/reconciler calls retry once; the research stage failing yields an empty digest, not a dead run.
  • 154 pytest tests over the deterministic layers (converters, baselines, backtests, nudge caps, gates, writer-vs-template asserts, cascade). LLM and network are mocked; real corpus files serve as fixtures. The workbook writer sha-asserts the supplied templates are never modified.

What we tried, changed, or got wrong (honesty section)

  • OpenBB as the data backbone — adopted, then dropped the same hour for a lean keyless tool belt (yfinance + ddgs + trafilatura) once we chose framework-level control. Fewer, debuggable parts won.
  • We guessed the wrong “golden document”. We assumed Hays’ newest filing (Aug 3) was the pre-close update; it was an administrative voting-rights notice. The real prize was the July 10 Q4 update — which the extraction pipeline found on its own.
  • A blind-integrity leak, found and sealed: Hays publishes company-compiled consensus in its RNS; extraction initially classified it as guidance, quietly placing a street number in the blind estimator’s context. Fixed with dedicated consensus fact types + load-time reclassification; that same discovery gave the reconciler a tier-1 consensus source.
  • Conservative degradation silently muted the model. With a 2-point series, σ was undefined and every judgment term multiplied to exactly zero — cited reasoning discarded without a trace. We now fall back to an MAE-derived scale and every degradation writes an audit note instead of a silent zero. A systematic sweep after this found four sibling bugs (tiny-n MAE caps, overconfidence rewarded by zero quantile spread, unlogged research-agent tokens, uncached digest).
  • Fixed validation bands were wrong for trending series — the 0.5–2×-of-median gate rejected Hays’ genuinely collapsing EPS as a “unit error”. Bands are now derived from the series’ own observed YoY ratios.
  • Run-to-run estimator variance is real. Two identical runs moved Hays net fees by ~12% purely on the model’s mood. Self-consistency sampling (k estimates, median, spread as extra shrinkage) is designed and deferred; if unshipped at judging time, it is our most acknowledged gap.

Known weaknesses

  • Blindness controls the context, not the model’s memory. These are famous tickers; pretrained priors are consensus-shaped. Actuals are post-cutoff so no answer leakage, but we deliberately rejected full anonymization (it would cost peer knowledge) and disclose the residual bias instead.
  • The vibe σ-multiples are declared, not fully calibrated. The time-travel calibration (label historical quarters as-of-date, measure label→outcome) is designed and budgeted but may not ship; until then the caps, citations-or-zero rule and shrinkage are the defence.
  • Sparse annual histories (Hays reports twice a year) leave some backtests at n=1–3; we floor the error scale rather than trust tiny samples, which is a heuristic.
  • The yfinance consensus mapping is the least-verified seam (index labels, revenue scale, Deere’s segment definitions); corpus-published consensus and magnitude gates reduce, not eliminate, the risk.
  • Keyless data sources rate-limit by IP; caches and politeness delays mitigate, venue wi-fi remains a risk we pre-bake against.

Reproducibility & cost

  • uv sync rebuilds the exact environment (Python 3.13, lockfile committed). Keys and models come from .env (template committed): MODEL_BIG / MODEL_SMALL, provider-switchable OpenRouter/OpenAI.
  • Prepare: uv run python -m pipeline.run --prepare --all (companies in parallel; re-runnable; --refresh bypasses caches).
  • Final command: uv run python -m pipeline.run --forecast --all — four workbooks + logs/run-<ts>/{events.jsonl, report.json, report.html}, ending with the contest’s own submission check.
  • Cost discipline: cache-first at both layers (stable-prefix prompts for provider-side caching; read-through disk cache for data), cheap model for extraction/labeling/research, big model only for estimate/reconcile. A full single-company run measured $0.11 on the development model; the projected full final run on the premium pair is ~$5–6 against the $50 budget. Every LLM call’s tokens (cached included) are in the run log.
